# 🚀 ResumeForge

> **AI-Powered Resume Analyzer with ATS Scoring, Skill Gap Analysis, Resume Health Check, Interview Question Generator & PDF Report Generation.**

ResumeForge is an intelligent web application that analyzes resumes against a job description and provides detailed insights to help candidates improve their chances of getting shortlisted.

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 🎯 ATS Compatibility Score
- 🛠 Skill Gap Analysis
- 💡 Missing Skills Detection
- ❤️ Resume Health Analysis
- 📊 Resume Success Prediction
- 📁 Project Quality Analysis
- 💼 Job Role-Based Analysis
- 🎤 Interview Question Generator
- 📑 Downloadable PDF Analysis Report
- 🎨 Modern & User-Friendly Interface

## 🚀 How It Works

1. Upload your resume in PDF format.
2. Select a job role or paste a custom job description.
3. ResumeForge extracts resume content.
4. Skills are matched against the job description.
5. ATS score is calculated.
6. Missing skills are identified.
7. Resume quality is evaluated.
8. Personalized interview questions are generated.
9. A detailed PDF report is created.

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/latikar2810/ResumeForge.git
```

Move into the project

```bash
cd ResumeForge
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
